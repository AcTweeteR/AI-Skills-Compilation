# Support

AI Skills Compilation supports the catalog, its documentation, and its contribution workflow. It does not provide
technical support for projects listed in the catalog.

## Choose the right channel

| Need | Channel |
| --- | --- |
| Suggest one public source | [Repository Suggestion](https://github.com/AcTweeteR/AI-Skills-Compilation/issues/new?template=repository_suggestion.yml) |
| Submit structured evidence | [New Skill Review](https://github.com/AcTweeteR/AI-Skills-Compilation/issues/new?template=new_skill_review.yml) |
| Report unclear or stale documentation | [Documentation](https://github.com/AcTweeteR/AI-Skills-Compilation/issues/new?template=documentation.yml) |
| Report a catalog or validator defect | [Bug Report](https://github.com/AcTweeteR/AI-Skills-Compilation/issues/new?template=bug_report.yml) |
| Ask about policy or interpretation | [Question](https://github.com/AcTweeteR/AI-Skills-Compilation/issues/new?template=question.yml) |
| Propose a maintainable improvement | [Feature Request](https://github.com/AcTweeteR/AI-Skills-Compilation/issues/new?template=feature_request.yml) |
| Report sensitive data or a malicious link | Follow the private process in [SECURITY.md](SECURITY.md) |

Before opening an issue, search existing profiles, issues, and pull requests. Never publish credentials, private
URLs, personal data, exploit details, or client information.

For installation, configuration, runtime, or bug support concerning an external project, use that project's own
documentation and support channels. Catalog inclusion does not make this repository responsible for external
software.
